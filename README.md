# BestBeachSetUp

Beach equipment rental and setup service at Tamarack Beach and Tower 36.

Customers can browse available gear, book a setup day, sign a liability waiver, and pay — all from their phone. Crew get a PIN-protected daily manifest with check-in/check-out and customer messaging.

## Stack

- React 18 + Vite
- Tailwind (CDN)
- lucide-react icons
- Stripe (payments — coming soon)
- Resend (email receipts — coming soon)

## Development

```bash
npm install
npm run dev
```

## Deploy

Deployed on Vercel. Push to `main` to trigger a redeploy.
